# Project 2: Intel Sustainability Journey
Build an interactive webpage that presents Intel's sustainability goals in a timeline format. Using AI and your knowledge of responsive design, you'll experiment with hover effects, transitions, and layouts to ensure it adapts seamlessly to both desktop and mobile.

Launch a Codespace to get started! Remember to Commit and Push your project changes to GitHub from Codespaces to prevent losing progress.

### Rubric
|Criteria|Requirements|Pts|
| --- | --- | ---: |
| Responsive Timeline | Timeline scrolls horizontally on large screens and stacks vertically on small screens, adapting seamlessly | 20pts |
| Interactive Milestone Cards | Milestones hide additional details by default and reveal them smoothly on hover | 10pts |
| CSS Styling & Layout | Thoughtful use of CSS for an aesthetic and design, including spacing and colors inspired by Intel’s branding | 10pts |
| Images Added To Timeline | Each card on the timeline has an image (note: choose images that fit the content!) | 10pts |
| __(BONUS)__ CSS Transforms | Applied at least one CSS transform (scale, shadow, or transition effects) to make cards more dynamic on hover | 5pts |
| __(BONUS)__ Scroll Snap Effect | Implemented smooth horizontal scroll snapping, enhancing user experience. | 5pts |
| __(BONUS)__ Custom Images | Replaced all placeholder images with AI-generated visuals tailored to each milestone | 5pts |

## Resume Description
Designed and built a responsive, interactive webpage using HTML, CSS, and Flexbox to present content in a timeline format. Applied AI-assisted coding workflows to develop, test, and refine layouts optimized for both desktop and mobile devices.
